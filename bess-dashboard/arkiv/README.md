# Arkiv

`Projektportfolj_standalone_2026-09-17.html` är originalet — en självbärande
HTML-fil med hela portföljen — som React-appen byggdes från vy för vy.
Alla 25 vyer är flyttade (september 2026), så filen används inte längre av
appen, bygget eller testen.

Den ligger kvar som referens för originalets beteende och beräkningar:
kommentarer i koden som hänvisar till "standalone-versionen" eller
"originalet" syftar på den här filen. Konstanterna i
`src/data/konstanter.js` är extraherade ur den.

Öppna den direkt i en webbläsare för att jämföra. Den sparar i sin egen
lagring och påverkar inte appens data.
